SWP07 任務與 GitHub Pages 部署指南

1. 專案建議檔案結構 

swp07-aqi-map/
├── index.html         # 主要地圖介面、Leaflet 邏輯與 API / Fallback 資料處理
├── README.md          # 專案介紹、資料集來源 (環境部 API dataset/40448) 與操作說明
└── LICENSE            # 開放授權條款 (例如 MIT)

2. 部署至 GitHub Pages 步驟

  1. 在 GitHub 上建立新建儲存庫（Repository），命名為 swp07-aqi-map（設定為 Public）。
  2. 於本地端開啟終端機，執行以下 Git 指令推送檔案： 
    git init
git add .
git commit -m "feat: complete SWP07 Taiwan AQI interactive map"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/swp07-aqi-map.git
git push -u origin main
  3. 前往 GitHub Repository 頁面，點選 Settings ➔ Pages。
  4. 在 Build and deployment 區塊中，Source 選擇 Deploy from a branch。
  5. Branch 選擇 main，資料夾選擇 /(root) 後按下 Save。
  6. 等待約 1~2 分鐘，即可點擊 GitHub 產生的網址開啟全球公開的 AQI 即時地圖網頁！
